# Electric Blue Designs

Create a modern, premium, single-page website with a strong **blacked-out dark theme** (deep black #0A0A0A background, subtle dark gradients) and elegant **electric blue accents** (#00BFFF / #00D4FF). The overall aesthetic is minimalist, luxurious, and high-tech with generous whitespace, smooth micro-animations, and sophisticated scroll-triggered effects.

### Hero Section – Scroll Storytelling (Main Visual Impact)

When the user first lands on the page, they see a full-screen hero with large, bold typography using **SF Pro Display Bold** for all headlines.

The text appears sequentially with smooth scroll-triggered animations:

1. First line appears: **"Zaprojektujemy"** in large white text.

2. As the user scrolls down, the word **"twoją"** fades in below it. "twoją" receives a dynamic **blue underline animation** that draws itself from left to right, perfectly synced with scroll progress (like a digital marker/brush stroke in electric blue).

3. Next, the phrase **"stronę internetową"** completes the headline.

After scrolling further, the company name **"WeScale"** appears prominently. The letters **"We"** get the same elegant **blue underline animation** that draws in sync with scroll.

All headline text must use **SF Pro Display Bold**. Body text can use SF Pro Regular or SF Pro Medium for excellent readability. Background should have very subtle moving particles or slow geometric shapes in dark blue tones for depth.

### Call-to-Action Buttons

Below the headline, create a prominent **pill-shaped button** (rounded, modern, with hover effects):

- Text: **"Otrzymaj darmowy projekt"**

- Electric blue border + subtle glow on hover

- On hover: scale + bright blue fill with white text

- Clicking this button smoothly scrolls to the Contact / WhatsApp section.

Directly below this button, place two smaller buttons side by side:

- Left: **"Zobacz wycenę"** (pill style, blue accent)

- Right: **"Opinie"** with a minimalist arrow icon pointing right

Next to the "Opinie" button, display **three overlapping circular avatars** (person icons) with a slight 3D overlapping effect, creating social proof.

### Testimonials Section

When the user clicks **"Opinie"**, it expands or scrolls to a clean testimonials area:

- Show the **two most important testimonials** first (use high-quality lorem ipsum text).

- Each testimonial in a sleek card with subtle blue accent line on the left.

- Include fictional client names and company logos for realism.

Below the testimonials, implement a **horizontal auto-scrolling image slider** (continuous movement in one direction – left to right). The images should be high-quality mockups of modern websites, team photos, or project screenshots. Make it smooth, infinite, and pause on hover.

### WhatsApp Contact Section (Target of the main CTA)

A dedicated, visually striking section with:

- Large, bold WhatsApp number: **+48 531 589 533** (using SF Pro Display Bold)

- Around the number, create a **living blue marker/brush stroke animation** that circles or highlights the number dynamically.

- Prominent WhatsApp and SMS buttons.

- Pre-filled message ready to send:

  > „Jestem zainteresowany darmowym projektem strony internetowej, jestem chętny do dalszej współpracy”

The section should have strong visual hierarchy, blue glows, and clear call-to-action.

### General Requirements:

- Fully responsive (mobile-first)

- Extremely smooth scroll animations (use GSAP or Framer Motion style)

- Fast loading, premium feel

- Navigation: minimal top bar with logo "WeScale" and "Kontakt" link

- Footer with basic links and copyright

- Color palette: #0A0A0A, #111111, white text, electric blue accents (#00BFFF, #00D4FF)

- All animations should feel premium, intentional, and not overwhelming

- Typography hierarchy: **SF Pro Display Bold** for all major headlines and key elements

Generate the complete website concept with beautiful, modern UI/UX. Prioritize elegance, trust, and conversion. Use dark luxury aesthetic with blue highlights.
